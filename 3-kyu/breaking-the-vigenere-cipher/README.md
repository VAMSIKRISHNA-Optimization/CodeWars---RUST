<h2><a href=https://www.codewars.com/kata/544e5d75908f2d5eb700052b/train/rust target="_blank">Breaking the Vigenère Cipher</a></h2><h3>3 kyu</h3><h2 id="task">Task</h2><p>Write a function that can deduce which key was used during a Vigenere cipher encryption, given the resulting ciphertext, and the length of that key.</p><h3 id="notes">Notes</h3><ul><li>The input string, as well as the encryption key, will consist of uppercase letters only</li><li>All texts will be in English</li></ul><hr><h3 id="vigenere-cipher">Vigenere cipher</h3><p>(For a full description, check the <a href="https://en.wikipedia.org/wiki/Vigen%C3%A8re_cipher#Description" data-turbolinks="false" target="_blank">wikipedia article</a>.)</p><blockquote><p>In a Caesar cipher, each letter of the alphabet is shifted along some number of places. For example, with a shift of <code>3</code>, <code>A</code> would become <code>D</code>, <code>B</code> would become <code>E</code>, <code>Y</code> would become <code>B</code>, and so on. The Vigenère cipher has several Caesar ciphers in sequence with different shift values.</p></blockquote><p>The secret key is selected, and then repeated until it becomes as long as the text you want to encrypt/decrypt (if the key ends up being longer than the text, the superfluous key-characters can be removed):</p><pre><code>text          =  "HELLOWORLD"original key  =  "ABCXYZ"repeated key  =  "ABCXYZABCX" (superfluous "YZ" at the end was removed)</code></pre><p>Each character of the key tells how many times a character of the original text standing at the same position has to be shifted:</p><pre><code>text:      H    E    L    L    O    W    O    R    L    D          ------------------------------------------------key:       A    B    C    X    Y    Z    A    B    C    X          ------------------------------------------------shift:     0    1    2   23   24   25    0    1    2   23          ------------------------------------------------result:    H    F    N    I    M    V    O    S    N    A</code></pre><p>A ciphertext can then be decrypted by applying the same shifts but with a negative sign:</p><pre><code>text:      H    F    N    I    M    V    O    S    N    A          ------------------------------------------------key:       A    B    C    X    Y    Z    A    B    C    X          ------------------------------------------------shift:     0   -1   -2  -23  -24  -25    0   -1   -2  -23          ------------------------------------------------result:    H    E    L    L    O    W    O    R    L    D</code></pre>
