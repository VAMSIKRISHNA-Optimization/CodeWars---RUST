<h2><a href=https://www.codewars.com/kata/596549c7743cf369b900021b/train/rust target="_blank">The search for Primes! Twin Primes!</a></h2><h3>6 kyu</h3><p>A twin prime is a prime number that is either 2 less or 2 more than another prime number—for example, either member of the twin prime pair (41, 43). In other words, a twin prime is a prime that has a prime gap of two. Sometimes the term twin prime is used for a pair of twin primes; an alternative name for this is prime twin or prime pair. (from wiki  <a href="https://en.wikipedia.org/wiki/Twin_prime" data-turbolinks="false" target="_blank">https://en.wikipedia.org/wiki/Twin_prime</a>)</p><p>Your mission, should you choose to accept it, is to write a function that counts the number of sets of twin primes from 1 to n. </p><p>If n is wrapped by twin primes (n-1 == prime &amp;&amp; n+1 == prime) then that should also count even though n+1 is outside the range.</p><p>Ex n = 10</p><p>Twin Primes are (3,5) (5,7) so your function should return 2!</p>
