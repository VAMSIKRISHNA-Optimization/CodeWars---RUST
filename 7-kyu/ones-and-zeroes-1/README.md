<h2><a href=https://www.codewars.com/kata/650a86e8404241005fc744ca/train/rust target="_blank">Ones and Zeroes</a></h2><h3>7 kyu</h3><p>Your task is to implement a function that examines a given string composed of binary digits (0s and 1s). The function should return <code>True</code> if:</p><ul><li><p>Every consecutive sequence of ones is immediately followed by an equal-length consecutive sequence of zeroes, and the number of ones is equal to the number of zeroes.</p></li><li><p>A leading zero always results in a <code>False</code> outcome.</p></li></ul><p>Here are some examples to illustrate the expected behavior of the function:<strong>Examples</strong></p><pre><code>- For the input "110011100010," the function should return True because every consecutive sequence of ones (e.g., "11," "111," "1") is followed by an equal-length consecutive sequence of zeroes.- For the input "101010110," the function should return False because the sequence of ones ("11") is not followed by an equal-length consecutive sequence of zeroes.- "111100001100" # True - "111" # False- "00110100001111 # False, although the number of zeroes and ones is equal, the consecutive sequence of ones (e.g., "11," "1," "1111") is not followed by an equal-length consecutive sequence of zeroes.</code></pre><p><strong>Notes</strong></p><ul><li>The input string will only contain digits <code>0</code> or <code>1</code>.</li><li>The length of the input string (<code>txt</code>) will be greater than zero.</li></ul>
