<h2><a href=https://www.codewars.com/kata/66c9186bb01defccbd40449d/train/rust target="_blank">Gould's sequence</a></h2><h3>7 kyu</h3><p>Gould's sequence<sup><a href="https://en.wikipedia.org/wiki/Gould%27s_sequence" data-turbolinks="false" target="_blank">wiki</a></sup> is an infinite integer sequence, named after Henry W. Gould<sup><a href="https://en.wikipedia.org/wiki/Henry_W._Gould" data-turbolinks="false" target="_blank">wiki</a></sup>, that counts how many odd numbers are in each row of Pascal's triangle<sup><a href="https://en.wikipedia.org/wiki/Pascal%27s_triangle" data-turbolinks="false" target="_blank">wiki</a></sup>. It consists only of powers of two<sup>*</sup>, and begins</p><pre><code>1, 2, 2, 4, 2, 4, 4, 8, 2, 4, 4, 8, 4, 8, 8, 16, ..</code></pre><p>Note that Gould's sequence is a fractal sequence<sup><a href="https://en.wikipedia.org/wiki/Fractal_sequence" data-turbolinks="false" target="_blank">wiki</a></sup>.</p><p>The binary logarithms ( exponents in the powers of two ) of Gould's sequence form an integer sequence</p><pre><code>0, 1, 1, 2, 1, 2, 2, 3, 1, 2, 2, 3, 2, 3, 3, 4, ..</code></pre><p><sup>*</sup> A companion kata in Lean, proving that all elements of Gould's sequence are powers of two, is <a href="https://www.codewars.com/kata/all-elements-of-goulds-sequence-are-powers-of-two/" data-turbolinks="false" target="_blank">here</a>.</p><h1 id="task">Task</h1><p>Define a function <code>gould</code> that produces an iterator that produces the values ( the logarithms ) of this infinite sequence.</p><p>It will be tested for up to <code>1 000 000</code> values.<br>( Try to resist the temptation to approximate <code>Infinity</code> with <code>a million</code> ! )</p>
