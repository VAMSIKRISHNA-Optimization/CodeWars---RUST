<h2><a href=https://www.codewars.com/kata/57fd696e26b06857eb0011e7/train/rust target="_blank">Hungarian Vowel Harmony (easy)</a></h2><h3>7 kyu</h3><p><a href="https://en.wikipedia.org/wiki/Vowel_harmony" data-turbolinks="false" target="_blank">Vowel harmony</a> is a phenomenon in some languages. It means that "A vowel or vowels in a word are changed to sound the same (thus "in harmony.")" (<a href="https://en.wikipedia.org/wiki/Vowel_harmony#Hungarian" data-turbolinks="false" target="_blank">wikipedia</a>). This kata is based on <a href="https://en.wikipedia.org/wiki/Vowel_harmony#Hungarian" data-turbolinks="false" target="_blank">vowel harmony in Hungarian</a>. </p><h3 id="task">Task:</h3><p>Your goal is to create a function <code>dative()</code> (<code>Dative()</code> in C#) which returns the valid form of a valid Hungarian word <code>w</code> in <a href="http://www.hungarianreference.com/Nouns/nak-nek-dative.aspx" data-turbolinks="false" target="_blank">dative case</a> i. e. append the correct suffix <code>nek</code> or <code>nak</code> to the word <code>w</code> based on vowel harmony rules.</p><h3 id="vowel-harmony-rules-simplified">Vowel Harmony Rules (simplified)</h3><p>When the last vowel in the word is</p><ol><li>a <em>front
